# 🛠️ Multi-Tools: Gerador de Senhas e QR Code

Uma aplicação web ágil e responsiva que reúne duas ferramentas essenciais para o dia a dia digital: um gerador de senhas altamente customizável e um gerador instantâneo de QR Codes. 

Este projeto resolve a dor de depender de sites de terceiros (muitas vezes repletos de anúncios) para tarefas rápidas de segurança e compartilhamento de links.

## 🚀 Tecnologias Utilizadas
* **HTML5:** Estruturação semântica.
* **Tailwind CSS:** Estilização utilitária e design responsivo.
* **JavaScript (Vanilla):** Lógica de geração de senhas e manipulação da interface.
* **QRCode.js:** Biblioteca para renderização nativa dos QR Codes.
